# 设计记录（历史文档）

这个目录里的文档是**建设 RecallOS 过程中的原始记录**，不是使用手册。

## 读之前请注意

**它们是在某台具体机器上写的，里面会出现真实的绝对路径**——比如
`C:\Users\<某人>\anaconda3\python.exe`。那些路径**只对写下它们的那台机器成立**，
换一台机器几乎肯定不存在。

不要把这里的路径当成「你需要准备的东西」。你需要的只有两样：

1. Python 3.9+
2. 那个目录里有 `bin/` 和 `brain/` 的 RecallOS 项目目录

`python bin/recall.py doctor` 会把你机器上的真实情况打印出来——**以它为准**。

## 这些文档的价值在哪

它们是**决策记录**：为什么选了 SQLite FTS5、为什么索引只当派生物、为什么
「不把没实现的功能报告为通过」被反复写进测试。想知道某个设计为什么长这样，
来这里翻比看代码注释更完整。
